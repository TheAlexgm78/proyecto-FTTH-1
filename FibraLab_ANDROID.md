# FibraLab para Android · Thealexgm78

Este es el paquete de la aplicación **FibraLab** para Android.

## Descargar APK
1. Entrar a la pestaña **Actions** de este repositorio.
2. Abrir **Compilar FibraLab APK**.
3. Seleccionar la ejecución más reciente que haya terminado con ✓.
4. Descargar el artefacto **FibraLab-Thealexgm78-APK**.
5. Extraer su ZIP. El archivo `app-debug.apk` se puede instalar en Android y compartir por WhatsApp o Drive.

## Código completo
El proyecto Android está comprimido en el archivo `FibraLab_Compilacion.txt` (ZIP codificado en Base64), que la compilación restaura automáticamente. La versión ZIP legible también se entregó en el chat.

## Funciones
Buscador de hilo/buffer/color, registro local de destinos, respaldo de datos y simulador de pérdidas de potencia. Trabaja sin conexión.

## Distribución
El artefacto de Actions es una versión **debug firmada para pruebas**. Para una distribución de larga duración, generar una APK de lanzamiento firmada con una clave personal que debe mantenerse privada. No subir la clave de firma al repositorio público.
