# Simulador FTTH

Proyecto educativo para aprender cómo se construye, documenta y diagnostica una red FTTH desde la OLT hasta la ONT del cliente.

## Primera versión

La interfaz inicial incluye:

- OLT
- ODF
- Mufa
- Splitter
- CTO / NAP
- ONT
- Cable de práctica de 12 fibras
- Código de colores visual
- Inspector de componentes

## Próximos módulos

1. Mufas con buffers y bandejas.
2. Empalmes fibra por fibra.
3. Guías de empalme.
4. Cables de 12, 24, 48, 96 y 144 fibras.
5. Presupuesto óptico en dB/dBm.
6. Splitters 1:2, 1:4, 1:8, 1:16 y 1:32.
7. Averías simuladas.
8. OTDR básico.
9. Modo práctica y modo examen.

## Ejecutar en tu computadora

Necesitas Node.js instalado.

```bash
git clone https://github.com/TheAlexgm78/proyecto-FTTH-1.git
cd proyecto-FTTH-1
npm install
npm run dev
```

Vite mostrará una dirección local, normalmente:

```
http://localhost:5173
```

Ábrela en el navegador.
